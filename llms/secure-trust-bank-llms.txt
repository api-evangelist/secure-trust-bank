# Secure Trust Bank

> Secure Trust Bank PLC is an award-winning UK specialist bank (LSE: STB), founded 1952, headquartered in Solihull, providing savings and specialist lending to over a million customers. As a UK ASPSP under PSD2 and the CMA Open Banking framework, its regulated account and payment products conform to the OBIE Read/Write and Open Data standards. Secure Trust Bank is a specialist lender (not a CMA9 bank) and publishes no bank-branded Open Banking developer portal; the API surfaces below reference the shared OBIE standard specifications its products conform to.

## APIs
- [Open Data API (OBIE v1.3)](https://openbankinguk.github.io/opendata-api-docs-pub/): Public reference data - ATMs, branches, product information.
- [Account & Transaction Information API (OBIE R/W v4.0, AIS)](https://openbankinguk.github.io/read-write-api-site3/): FAPI-secured account, balance, transaction, standing-order and statement data with PSU consent.
- [Payment Initiation API (OBIE R/W v4.0, PIS)](https://openbankinguk.github.io/read-write-api-site3/): FAPI-secured domestic, scheduled, standing-order, international and file payments.
- [Confirmation of Funds API (OBIE R/W v4.0, CBPII)](https://openbankinguk.github.io/read-write-api-site3/): FAPI-secured yes/no funds-available confirmation for card issuers.
